{%- comment -%} Swappable gallery-title component. The viewer engine (layout, navigation, metadata line) knows nothing about how a title is presented -- it just includes this, and this file owns every style decision. Params: style a preset name. Currently only `magazine` is implemented; anything else (including omitted) renders the inert `plain` preset, which draws nothing at all. title the gallery's title text. The gallery NAME only -- never the photo number, which belongs to the viewer's metadata line. Presets live in _sass/tale/_gallery-title.scss, one block per preset, keyed off the `gallery-title--
