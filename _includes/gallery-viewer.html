{%- comment -%} The gallery viewer IS the gallery page -- there is no thumbnail grid. This is the site's one deliberate JavaScript exception (assets/js/gallery-viewer.js, also loaded by _pages/galleries.html for consistent title sizing there), because cross-photo navigation has no pure-CSS mechanism. Without JS, the slide strip is still a real, native CSS scroll-snap carousel -- swipe/scroll works, just without synced info, buttons, or the title/note behavior. Slide 1 is the gallery's cover: its title renders permanently (not the transient flash the other slides get) and its info panel shows the gallery's own title/date/description instead of that photo's EXIF/note. Slide 2 is an auto-generated duplicate of the same photo -- same cover info, but normal (flash-then-fade) title behavior, so leaving the cover reads as the title quietly fading rather than an abrupt swap. This one page, at its own URL, IS how a gallery gets linked. Each slide carries its own pre-rendered info panel (a chip list for a real photo, a labeled block for the cover/its duplicate) -- built once at Liquid time, not assembled from a flat string at runtime, so wrapping is just CSS flex-wrap on real markup, never a truncated single line. The script only decides which panel is visible and where it sits (beside the photo in the gutter, or below it), never what it says. Reads page.photos (basename / alt / note / place / country / exif), page.title_style, page.title_position, page.license, page.title, page.date, and page.description (the gallery's own flavor text -- same rules as a photo's note). {%- endcomment -%} {%- capture cover_title_line -%}Title: “{{ page.title | escape }}”{%- endcapture -%} {%- capture cover_date_line -%}{% if page.date %}Publication date: {{ page.date | date: "%B %Y" }}{% endif %}{%- endcapture -%} {%- comment -%} Captured once, used by both the cover slide and its auto-generated duplicate below -- the two are identical except for title behavior, which JS decides purely from slide position (index 0 vs. not), not from anything in this markup. {%- endcomment -%} {%- capture cover_info_block -%}
